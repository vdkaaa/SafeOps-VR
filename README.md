# SafeOps VR

Simulador de entrenamiento en seguridad industrial para Meta Quest 3.
Proyecto de portafolio — arquitectura de producción, no prototipo.

## Stack
- Unity 6 LTS · URP
- OpenXR · XR Interaction Toolkit 3.x · Meta XR Core SDK
- C# · Input System

## Escenas
1. Inducción y equipamiento de EPP
2. Operación de grúa horquilla
3. Bloqueo y etiquetado (LOTO)

## Estado
En desarrollo — Semana 1: infraestructura base.

## Build
Target: Android (Meta Quest 3) · IL2CPP · ARM64 · Vulkan
